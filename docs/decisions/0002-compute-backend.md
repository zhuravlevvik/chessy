# ADR-0002: Вычислительный backend

Статус: утверждено
Дата: 2026-08-06

## Решение

- Использовать PyTorch как основной ML-framework.
- Использовать MPS для обучения и batch inference на Apple Silicon.
- Поддерживать CPU как обязательный fallback и эталон для unit-тестов.
- Сохранять возможность запуска того же PyTorch-кода на CUDA.
- Не реализовывать MLX-backend до появления измеренного узкого места.
- Направлять запросы CPU self-play workers в единый batching inference service
  на MPS, а не давать каждому процессу независимо обращаться к GPU.

## Причины

PyTorch упрощает обучение, полные snapshots, отладку и переносимость. MPS даёт
доступ к встроенному GPU текущего Mac. Единый inference service позволяет
эффективно собирать позиции MCTS в batches и избегать конкуренции процессов за
GPU.
