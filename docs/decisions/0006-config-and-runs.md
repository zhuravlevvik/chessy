# ADR-0006: Конфигурация и идентификация run

Статус: утверждено
Дата: 2026-08-06

## Решение

- Писать исходные конфигурации в YAML формата `chessy-config-v1`.
- Валидировать их строгими Pydantic-моделями с запретом неизвестных полей.
- Сохранять полную resolved-конфигурацию как canonical JSON.
- Формировать run ID из времени, читаемого имени и fingerprint конфигурации.
- Фиксировать Git commit, hash `uv.lock`, версии среды и dataset manifests.
- `resume` использует сохранённую конфигурацию; изменение эксперимента выполняет
  `fork`. Эксплуатационные overrides записываются как события run.

## Причины

YAML удобен человеку, Pydantic предотвращает тихие ошибки, а canonical JSON
обеспечивает стабильное хеширование и сравнение запусков.
