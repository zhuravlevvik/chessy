# ADR-0007: Локальный игровой интерфейс

Статус: утверждено
Дата: 2026-08-06

## Решение

- Backend: FastAPI и WebSocket.
- Frontend: React, TypeScript, Vite и `react-chessboard`.
- Backend является источником правил, часов, состояния игры, MCTS и PGN.
- Собранный frontend раздаётся FastAPI и запускается командой `chessy play`.
- Сервер слушает только `127.0.0.1` и автоматически выбирает свободный порт.
- Галочка добавления в обучение выключена по умолчанию; после партии требуется
  отдельное подтверждение.
- Скачивание PGN не зависит от включения human-feedback.

## Проверка среды

На рабочем Mac успешно проверено открытие случайного loopback-порта и локальное
HTTP-подключение. Внешний сетевой интерфейс для игры не требуется.
