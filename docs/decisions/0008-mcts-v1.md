# ADR-0008: Начальная конфигурация MCTS

Статус: утверждено
Дата: 2026-08-06

## Решение

Использовать версионируемый алгоритм `mcts-puct-v1`.

- PUCT с `c_puct = 1.5`.
- Value задаётся относительно стороны хода и меняет знак при backup на ply.
- В self-play root prior смешивается с Dirichlet noise:
  `alpha = 0.3`, `epsilon = 0.25`.
- В arena и игре с человеком root noise выключен.
- Curriculum использует 64/96/128 симуляций для простых окончаний,
  уменьшенного материала и полных шахмат соответственно.
- Игровые профили: fast 32, normal 128, deep 512.
- Arena использует 128 симуляций, temperature 0 и парные позиции со сменой цвета.
- MPS inference service собирает batches до 32 позиций с начальным ожиданием до
  2 мс; стартовая конфигурация — 6 workers по 4 параллельные партии.
- Дерево повторно используется после хода.
- Resignation выключен до отдельной калибровки value.
- Защитный предел партии — 300 полуходов с отдельной причиной ничьей.
- Self-play temperature равна 1 в начале curriculum-партии и затем переходит к
  argmax; длина исследовательской фазы задаётся стадией.

## Профилирование

Число симуляций, размер batch и количество workers являются параметрами run и
могут меняться через `fork` после измерения throughput. Формула PUCT, backup и
кодирование статистики дерева входят в контракт `mcts-puct-v1`.
