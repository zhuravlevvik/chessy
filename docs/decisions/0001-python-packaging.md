# ADR-0001: Python и управление зависимостями

Статус: утверждено
Дата: 2026-08-06

## Решение

- Использовать Python 3.12.
- Управлять проектом и зависимостями через `uv`.
- Хранить декларацию зависимостей и настройки инструментов в `pyproject.toml`.
- Версионировать точное разрешение зависимостей в `uv.lock`.
- Использовать локальное виртуальное окружение `.venv`.
- Размещать пакет в `src/chessy/`, тесты — в `tests/`.
- После миграции не поддерживать отдельный ручной `requirements.txt` параллельно
  с `uv.lock`.

## Причины

Решение даёт изоляцию от системного Python, воспроизводимые установки,
фиксированные версии зависимостей и единый способ запуска разработки,
тестирования, обучения и интерфейса.
